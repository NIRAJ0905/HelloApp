# HelloApp

HelloApp is a Java learning project.

The project evolves step by step from a simple Hello World program into a modular console application.

Features implemented step by step:

- Print Hello World
- Accept command line arguments
- Read input from standard input
- Store names in collections
- Remove names
- Refactor into classes
- Persist names across runs
- Display names in banner format

Technologies used:
- Java
- Maven
- Git
